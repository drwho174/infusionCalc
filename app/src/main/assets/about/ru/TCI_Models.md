# Пропофол TCI

Калькулятор для расчёта скорости инфузии по заданной концентрации:
вы задаёте целевую концентрацию пропофола (Cp — в плазме или Ce — в месте
действия), модель и данные пациента, а приложение рассчитывает болюс,
скорости поддержания, прогноз Cp/Ce во времени и подсказывает установки
для ручного шприцевого насоса.

## Модели Marsh и Schnider

Краткая справка по фармакокинетическим моделям пропофола, которые используются
в карточке TCI. Подробные формулы и правила расчёта — в `docs/SPEC-TCI.md` §5.2, §6.

### Marsh

| Параметр | Формула |
|---|---|
| `V1` | `0.228 × вес` |
| `V2` | `0.4643 × вес` |
| `V3` | `2.895 × вес` |
| `CL1` | `0.027 × вес` |
| `CL2` | `0.0255 × вес` |
| `CL3` | `0.0095 × вес` |
| `ke0` | `0.26 мин⁻¹` |

- Нужен только **вес**.
- Возраст, рост и пол не влияют.
- Простая и распространённая модель; удобна, когда нет антропометрии.
- Формального ограничения по ИМТ нет, но при выраженном ожирении
  точность популяционного прогноза снижается.

### Schnider

| Параметр | Формула |
|---|---|
| `V1` | `4.27 л` (фиксированный) |
| `V2` | `18.9 − 0.391 × (возраст − 53)` |
| `V3` | `238 л` |
| `CL1` | `1.89 + 0.0456 × (вес − 77) − 0.0681 × (LBM − 59) + 0.0264 × (рост − 177)` |
| `CL2` | `1.29 − 0.024 × (возраст − 53)` |
| `CL3` | `0.836` |
| `ke0` | `0.456 мин⁻¹` |

- Нужны **вес, рост, возраст и пол**.
- `LBM` (тощая масса, формула James):
  - мужчины: `1.10 × вес − 128 × (вес / рост)²`
  - женщины: `1.07 × вес − 148 × (вес / рост)²`
- Учитывает возраст, пол и рост; `ke0` выше, поэтому Ce быстрее
  приближается к плазме.
- Ограничение по ИМТ: **мужчины < 42**, **женщины < 35 кг/м²**.
  Вне диапазона приложение предупреждает — модель может давать заметную ошибку.

## Чем отличаются

| | Marsh | Schnider |
|---|---|---|
| Данные пациента | вес | вес, рост, возраст, пол |
| `V1` | зависит от веса | фиксированный |
| Влияние возраста/пола | нет | есть |
| `ke0` | 0.26 | 0.456 |
| Ограничение по ИМТ | нет | < 42 (М) / < 35 (Ж) |
| Когда удобна | есть только вес | есть полная антропометрия |

## Что считает приложение

- **Болюс:** `доза = целевая концентрация × V1`, объём = доза / концентрация
  препарата, время — при заданной скорости болюса.
- **Начальная скорость поддержания:** `R0 = C × (CL1 + CL2 + CL3)`.
- **Установившаяся скорость:** `R∞ = C × CL1`.
- **Cp/Ce во времени** — пошаговая симуляция; ступени поддержания
  рассчитываются для ручного насоса (по умолчанию каждые 5 минут,
  шаг настраивается в TCI-настройках).

## Какую модель выбрать

- **Schnider** — если есть рост, возраст и пол, а ИМТ в допустимом диапазоне:
  модель учитывает больше факторов.
- **Marsh** — если известен только вес или ИМТ выходит за ограничения Schnider
  (с пониманием, что прогноз менее индивидуализирован).
- Обе модели — **популяционные**: прогноз не равен измеренной концентрации.

## Ограничения

- Только **взрослые**, только анестезия; не для седации и не для детей.
- Не учитываются сопутствующие препараты, гемодинамика, печёночно-почечная
  функция и индивидуальная чувствительность.
- В режиме **Ce** болюс считается по той же формуле `C × V1`; это упрощение,
  ориентируйтесь на прогноз Ce.
- Приложение не управляет насосом и не заменяет клиническую оценку глубины
  анестезии и мониторинг.
