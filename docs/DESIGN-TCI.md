## 1. Принципы дизайна TCI

| ID | Принцип | Что это значит в UI | Требования |
|---|---|---|---|
| DTC-1 | **Числа первичны, график вторичен** | Болюс, скорость, Cp/Ce — крупно и всегда видимы; график — ниже, как контекст динамики | NFR-TCI-A11Y-02, FR-TCI-PLOT-01/02 |
| DTC-2 | **Модель и режим задаются первыми** | Модель/режим — вверху, поля пациента появляются по модели | FR-TCI-MDL-01/02 |
| DTC-3 | **Этапы не ведутся** (v1.3) | Чек-лист удалён; ориентир — текущая цель и живые Cp/Ce | D-TCI-12, задание t8 |
| DTC-4 | **Прогноз всегда подписан** | Cp/Ce сопровождается строкой «прогноз модели, не измеренная концентрация» | FR-TCI-DISC-01, ⛔-TCI-5 |
| DTC-5 | **Безопасность не отключается** | Дисклеймер и предупреждения не модальные, не закрываются | FR-TCI-SAFE-02, FR-TCI-DISC-02 |
| DTC-6 | **Одна рука, тёмная операционная** | Тач-цели 48 dp, крупные цифры, тёмная тема обязательна | NFR-TCI-A11Y-01/02 |

## 2. Макет экрана S-TCI

Порядок блоков сверху вниз фиксирован. Ниже — структурированная схема-раскладка с подписями элементов (читается как визуальный макет экрана).

```
┌───────────────────────────────────────────────────────────────┐
│ S-TCI · Пропофол (TCI)                                     [⚙]│ ← Верхняя панель: назад, заголовок, настройки TCI
├───────────────────────────────────────────────────────────────┤
│ 1. Модель и режим                                             │ ← Секция (SectionCard)
│   Модель:   ( Marsh )  ( Schnider )        ← сегментированный  │
│   Режим:    ( Плазма Cp ) ( Место действия Ce )                │
├───────────────────────────────────────────────────────────────┤
│ 2. Данные пациента                                            │
│   Вес       [ 70   ] кг                                       │
│   Рост      [ 170  ] см      ← видно только для Schnider       │
│   Возраст   [ 40   ] лет     ← видно только для Schnider       │
│   Пол       ( Мужской ) ( Женский )  ← только для Schnider     │
├───────────────────────────────────────────────────────────────┤
│ 3. Целевая концентрация и препарат                             │
│   Концентрация: ( 10 мг/мл (1%) ) ( 20 мг/мл (2%) )            │
│   Цель Cp    [ 4.0  ] мкг/мл   ← меняется и во время инфузии   │
│   ─ Диапазон Cp 3–8 · Ce 2.5–4 мкг/мл (подсказка)              │
├───────────────────────────────────────────────────────────────┤
│ 4. Болюс и таблица скоростей                                   │
│   Болюс:      6.38 мл   за 00:19                               │
│   [ Таблица скоростей (каждые 5 мин) ]   ← раскрывается         │
├───────────────────────────────────────────────────────────────┤
│ 5. Скорость и концентрация                                     │
│   ┌─────────────────────────────────────────────┐              │
│   │ Насос · поддержание                          │ ← PumpCard    │
│   │        56.7 мл/ч               ← 1 знак      │              │
│   │ Следующая коррекция через 04:12 → 52.9 мл/ч  │              │
│   │ [ Выставил(а) ]   [ Скорость вручную… ]      │              │
│   └─────────────────────────────────────────────┘              │
│   Текущие:  Cp 4.00 мкг/мл   Ce 2.91 мкг/мл   ← крупно (tnum)  │
│   ┌─────────────────────────────────────────────┐              │
│   │      Cp ────   Ce ─ ─ ─                    │ ← график Cp/Ce │
│   └─────────────────────────────────────────────┘              │
│   0′        5′        10′        (ось X, мин)                  │
├───────────────────────────────────────────────────────────────┤
│ 6. Сессия инфузии  ← предпоследняя карточка                    │
│   [ Старт инфузии ]   /   после старта: 12:34 · идёт           │
│   [ Пауза ]  [ Стоп ]                                          │
├───────────────────────────────────────────────────────────────┤
│ 7. Время до пробуждения                                        │
│   Порог: [1.5] мкг/мл (1.0–2.0)   Время: 12:40  ← крупно       │
│   ─ при паузе — обратный отсчёт от момента паузы               │
└───────────────────────────────────────────────────────────────┘
```

Подписи элементов:

| # | Блок | Ключевые элементы и подписи | Требования |
|---|---|---|---|
| 1 | Шапка | Назад → S-1; заголовок «Пропофол (TCI)»; настройки TCI (скорость болюса, показ дисклеймера) | FR-TCI-NAV-01, FR-TCI-LIVE-08 |
| 2 | Дисклеймер | Диалог при открытии: текст + «Больше не показывать»; повторно — из настроек | FR-TCI-DISC-01/02 |
| 3 | Модель и режим | Сегментированный выбор; смена сбрасывает расчёт (MSG-TCI-05) | FR-TCI-MDL-01/04, FR-TCI-TGT-01 |
| 4 | Данные пациента | Поля по модели: Marsh — только вес; Schnider — вес+рост+возраст+пол | FR-TCI-MDL-02/03 |
| 5 | Цель и препарат | Концентрация (пресеты), цель с суффиксом режима; цель меняется и во время инфузии | FR-TCI-TGT-02, FR-TCI-CONC-01, FR-TCI-LIVE-07 |
| 6 | Болюс и таблица скоростей | Объём болюса и время; таблица ступеней (раскрываемая); скорость болюса — в настройках | FR-TCI-BOL-01, FR-TCI-MAINT-01, FR-TCI-LIVE-08 |
| 7 | Скорость и концентрация | PumpCard + Cp/Ce + график; скорости с одним знаком | FR-TCI-PLOT-01/02, FR-TCI-LIVE-02/03 |
| 8 | Сессия инфузии (предпоследняя) | Старт/Пауза/Продолжить/Стоп; секундомер; статус | FR-TCI-LIVE-01 |
| 9 | Время до пробуждения | Порог и время; при паузе — обратный отсчёт | FR-TCI-WAKE-01…03 |


## 3. Компоненты TCI

| Компонент | Ключевое |
|---|---|
| **C-TCI-2 SegmentControl (модель/режим/концентрация/пол)** | Сегментированный контрол M3; выбранный — `secondaryContainer`; тач-цели 48 dp |
| **C-TCI-3 BolusCard** | Болюс (мл) крупно + «за мм:сс»; фон `primaryContainer`. Скорость болюса задаётся в настройках из appbar |
| **C-TCI-4 MaintenanceRow** | «старт R0 → установившаяся R∞» + таблица скоростей по времени (раскрываемая) |
| **C-TCI-5 CpCeChart** | Кривые Cp (сплошная) и Ce (пунктир), легенда; ось X — мин, Y — мкг/мл; числа текущих Cp/Ce вынесены над графиком (не только в графике) |
| **C-TCI-6 WakeTimeCard** | Порог (1.0–2.0, умолчание 1.5) + время «мм:сс/чч:мм»; при паузе — обратный отсчёт по живой симуляции выведения |
| **C-TCI-7 TciDisclaimerDialog** | Диалог при открытии экрана (текст дисклеймера + чекбокс «Больше не показывать»); повторно вызывается из настроек TCI |
| **C-TCI-8 SessionPanel** | Строка «Старт/Пауза/Стоп» + секундомер `мм:сс`/`чч:мм:сс`; статус «идёт/пауза»; экран не гаснет. Во время сессии заблокированы модель/пациент/концентрация, цель менять можно |
| **C-TCI-9 PumpCard** | `primaryContainer`: фаза, скорость `headlineLarge` **с одним знаком** после запятой, «Следующая коррекция через мм:сс» и следующая скорость, «Выставил(а)» (после подтверждения — «Выставлено»), «Скорость вручную…», ошибка просрочки `error` |
| **C-TCI-10 LiveStatus** | Cp/Ce и время пробуждения обновляются каждую секунду, в том числе на паузе; `liveRegion=Polite` — сводка «Cp · Ce · пробуждение» не чаще 1 раза в 30 с. Курсор на графике, ось X растягивается для сессий > 60 мин |

## 4. Доступность (WCAG 2.2 AA)

Дополнительно к `docs/DESIGN.md` §8:

- **Крупные цифры (NFR-TCI-A11Y-02):** текущие Cp/Ce, болюс и время до пробуждения — `tnum`, роль не ниже `headlineSmall` (24 sp), на широких экранах — `headlineMedium`; масштабируются до 200 % без обрезки.
- **Цвет не единственный носитель смысла:** статусы сессии и просрочка — текст + иконка; кривые графика различаются типом линии (сплошная/пунктир) **и** легендой, а не только цветом; предупреждения — иконка + текст.
- **График дублируется числами:** TalkBack читает текущие Cp/Ce и время до пробуждения; `stateDescription` графика: «График Cp и Ce. Значения: Cp …, Ce …».
- **Порядок обхода = визуальный:** шапка → дисклеймер-диалог → модель/режим → пациент → цель → болюс → скорость и график → сессия → пробуждение.
- **liveRegion=Polite** для Cp/Ce и времени до пробуждения — сводка обновляется не чаще 1 раза в 30 с (NFR-TCI-A11Y-03), чтобы TalkBack не озвучивал каждую секунду; крупные цифры меняются визуально каждую секунду.

## 5. Локализация RU/EN

- Единицы: `мкг/мл` / `mcg/mL`, `мл/ч` / `mL/h`, `мг/мл` / `mg/mL`, `см` / `cm`, `кг` / `kg`, `лет` / `years`.
- Режимы: «Плазма Cp» / “Plasma Cp”; «Место действия Ce» / “Effect-site Ce”.
- Модели: «Marsh» / “Marsh”; «Schnider» / “Schnider” (имена не переводятся).
- Сообщения — `MSG-TCI-01…07` (RU/EN), дисклеймер — `tci_disclaimer` (SPEC-TCI §7.3).
- Формат чисел — по языку приложения (RU `,`, EN `.`), без группировки разрядов.

## 6. Состояния экрана

| Состояние | Признак | Поведение |
|---|---|---|
| default | модель/режим/концентрация по умолчанию, поля пусты | подсказки, расчёт не выполнен |
| loading | симуляция (≤ 100 мс) | индикатор в блоке болюса/графика |
| incomplete | не хватает полей модели | блокировка с MSG-TCI-01, указание поля |
| warning | BMI вне ограничения / цель вне диапазона | баннер MSG-TCI-03/04, расчёт доступен |
| blocking | технический предел / BMI strict | расчёт недоступен, MSG-TCI-01/03 |
| ready | все поля валидны | болюс/скорости/график/время рассчитаны |
| error | неожиданный сбой движка | `Invalid(reason)` → MSG-TCI-01, без NaN |
| session-idle | расчёт готов, сессия не начата | кнопка «Старт инфузии», подсказка о шагах 5 мин |
| session-running | сессия идёт | секундомер, PumpCard у графика, живые Cp/Ce; модель/пациент/концентрация заблокированы, цель меняется |
| session-paused | пауза вручную | насос 0 мл/ч; часы и график идут, Cp/Ce выводятся; в карточке пробуждения идёт отсчёт; ввод заблокирован (кроме цели) |
| session-overdue | уставка не подтверждена > 60 с | предупреждение «коррекция просрочена» в PumpCard |
| session-manual | задана ручная скорость | плановые подсказки скрыты, прогноз считается от ручной скорости |
| session-restored | снимок найден после kill/перезагрузки | время догнано по часам, баннер о восстановлении не модальный |
| session-target | цель изменена во время инфузии | PumpCard показывает доп. болюс (мл и время) и новые ступени; при снижении цели болюса нет |
| disclaimer | первый вход, «больше не показывать» не отмечено | диалог дисклеймера; повторно — из настроек TCI |

## 7. Крайние случаи

| № | Случай | Поведение |
|---|---|---|
| E-TCI-1 | Смена Marsh→Schnider при непустых полях | Подтверждение MSG-TCI-05; рост/возраст/пол появляются пустыми, расчёт сброшен |
| E-TCI-2 | Смена Cp→Ce | Симуляция сброшена; подпись цели меняется; подсказка диапазона — по Ce |
| E-TCI-3 | BMI жен. 100 кг/165 см (36.73 > 35) | MSG-TCI-03, предупреждение/блок |
| E-TCI-4 | Цель 9 мкг/мл (Cp) | MSG-TCI-04, расчёт не блокируется |
| E-TCI-5 | Концентрация 20 мг/мл вместо 10 | Объёмные скорости и болюс вдвое меньше (TEST-TCI-G6) |
| E-TCI-6 | Вес 150 кг | MSG-TCI-02 (правдоподобие), расчёт продолжается |
| E-TCI-7 | «0,» / «,» в поле | Partial, без красного (SPEC VAL-07) |
| E-TCI-8 | Время до пробуждения > 60 мин | «чч:мм» |
| E-TCI-9 | Поворот экрана | Значения сохраняются, клавиатура закрывается |
| E-TCI-10 | Убийство процесса во время сессии | Снимок активной сессии (D-LIVE-4) восстанавливает время и уставки; после «Стоп» снимок удалён |

## 8. Трассировка к SPEC-TCI

Макет §2 покрывает FR-TCI-NAV-01, FR-TCI-MDL-01…04, FR-TCI-PAT-01…04, FR-TCI-TGT-01…04, FR-TCI-CONC-01/02, FR-TCI-BOL-01, FR-TCI-MAINT-01, FR-TCI-PLOT-01/02, FR-TCI-WAKE-01/02, FR-TCI-SAFE-01…03, FR-TCI-DISC-01/02, FR-TCI-LIVE-01…10, CALC-TCI-15/16. Компоненты C-TCI-2…10 — реализация этих требований. Доступность и локализация — NFR-TCI-A11Y-01/02, NFR-TCI-I18N-01.

## 9. Критерии приёмки дизайна

1. Макет §2 читается как визуальный макет: 7+ блоков сверху вниз с подписями элементов.
2. Поля пациента зависят от модели; смена модели/режима сбрасывает состояние (E-TCI-1/2).
3. Болюс, скорости, Cp/Ce и время до пробуждения — крупными цифрами, график вторичен.
4. Доступность §4 и локализация §5 выполнимы; цвет не единственный носитель смысла.
5. Нет противоречий с `docs/DESIGN.md` и `docs/SPEC-TCI.md`; расхождения — в §11.
