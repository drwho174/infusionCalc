## 0. Как читать документ

### 0.1 Идентификаторы

Идентификаторы TCI-области имеют суффикс `-TCI-` и **не пересекаются** с `docs/SPEC.md` (там нумерация `FR-*`, `DATA-*`, `CALC-*`, `ACC-*`, `TEST-*`, `D-*`, `OQ-*`, `RISK-*`, `⛔-*` без суффикса). Ссылки на базовый SPEC даются как `SPEC §…` или `SPEC FR-…`.

### 0.2 Приоритеты

То же соглашение, что в `SPEC §0.2`: **must** (блокирующий дефект при отсутствии) / **should** (нужно в v1.0, при срыве срока — осознанный перенос) / **could** (не влияет на выпуск).

### 0.3 Маркеры достоверности

То же соглашение, что в `research-tci.md §0`: **✅** проверено по первичному источнику; **⚠️** допущение/решение, требующее клинического подтверждения, либо подтверждено только по индексации PDF; **⛔** прямо запрещено.

### 1.4 Новая осознанная область: точная ссылка на снятое ограничение

**Точное место ограничения.** Исключение фармакокинетики зафиксировано в `docs/SPEC.md` **§6.8 п.1** («Не моделируется фармакокинетика, полувыведение, кумуляция, тахифилаксия» → «Приложение считает скорость введения, не концентрацию в плазме») и в `docs/research-clinical.md` **§3.8 п.1–2** («Не моделируется фармакокинетика… не моделируется время полужизни, тахифилаксия, кумуляция»). Смежное исключение — `SPEC §1.3 п.5` (дозирование на м², идеальная/скорректированная масса тела, BSA), поскольку Schnider опирается на LBM (James) — телесную ковариату.

> Примечание о ссылке в задании: в постановке t2 названо «SPEC.md §1.3 п.1». В тексте `docs/SPEC.md` §1.3 п.1 — это «капли/мин», а фармакокинетика исключена в **§6.8 п.1**; §1.3 п.5 исключает идеальную массу/BSA. Ниже ссылки даются на фактические места.

**D-TCI-1. TCI-карточка пропофола — новая осознанная область, а не «тихое» расширение скоупа.** Она явно и ограниченно снимает `SPEC §6.8 п.1` / `research-clinical §3.8` только для пропофол-TCI у взрослых (анестезия). Это не меняет базовый калькулятор «доза ⇄ скорость» (он по-прежнему не моделирует фармакокинетику). Обоснование: `research-tci.md` R1 («TCI — отдельный режим, не схема мкг/кг/мин»), образец B.Braun Perfusor Space. Влияние: вводится отдельный экран S-TCI и отдельная модель данных §5; правила §6 применяются только к нему.

## 2. Аудитория и сценарии

### 2.1 Персона

| Персона | Задача | Что критично | Требования |
|---|---|---|---|
| **Анестезиолог** (взрослый, RU/EN, в операционной) | Задать модель и пациента, получить болюс/скорость, следить за Cp/Ce, спрогнозировать пробуждение | Проверяемость (модель, формула, источник), крупные цифры, предупреждения о выходе цели за диапазон, одна рука | FR-TCI-*, NFR-TCI-A11Y, MSG-TCI-* |

Отличие от базовой аудитории SPEC §2: TCI-карточка адресована анестезиологу, а не врачу ОРИТ/медсестре у постели; контекст — плановая анестезия, где важна динамика Cp/Ce во времени, а не мгновенный пересчёт «доза ⇄ скорость».

### 2.2 Контекст использования

Операционная, плохое освещение, спешка при индукции, одна рука; результат должен читаться с расстояния; график — вспомогательный, численные значения — первичны. Тёмная тема обязательна (наследуется из SPEC §8.8). Клавиатура сама не открывается (SPEC FR-CALC-15 переносится).

### 2.3 Сценарии (обязательные)

**SC-TCI-1. Индукция по Schnider (Ce-режим), 60 секунд до болюса**
1. S-1 → «Пропофол (TCI)» → S-TCI.
2. Модель = Schnider; режим = Ce (место действия); концентрация = 10 мг/мл.
3. Данные пациента: вес 70, рост 170, возраст 40, пол мужской.
4. Цель Ce = 4 мкг/мл.
5. Экран показывает: болюс 17.08 мг = 1.708 мл (≈1.7 мл), начальная скорость 97.8 мл/ч, Ce(3 мин) ≈ 2.98 мкг/мл; чек-лист «Индукция» активен.
→ FR-TCI-PAT-01…03, FR-TCI-BOL-01, FR-TCI-TGT-02; ACC-TCI-2; TEST-TCI-G3.

**SC-TCI-2. Marsh (Cp-режим), отметка этапов**
1. Модель = Marsh; режим = Cp; вес 70; цель Cp = 4; концентрация 10 мг/мл.
2. Болюс 63.84 мг = 6.384 мл; R0 = 104.16 мл/ч; R∞ = 45.36 мл/ч.
3. Пользователь отмечает «Индукция выполнена» → активна «Поддержание»; после стопа — «Пробуждение» и время до пробуждения.
→ FR-TCI-STAGE-01…03, FR-TCI-WAKE-01; ACC-TCI-3; TEST-TCI-G1.

**SC-TCI-3. BMI-блок Schnider**
1. Schnider, жен. 100 кг / 165 см → BMI = 36.73 > 35 → предупреждение/блок, расчёт недоступен.
→ VAL-TCI-04, MSG-TCI-03; ACC-TCI-6; TEST-TCI-G9.

**SC-TCI-4. Цель вне диапазона**
1. Cp-цель = 9 мкг/мл → предупреждение «выше рекомендуемого диапазона индукции (4–8 мкг/мл)», расчёт не блокируется (если в технических пределах).
→ VAL-TCI-05, MSG-TCI-04; ACC-TCI-7.

## 3. Термины

| Термин | Определение |
|---|---|
| TCI | Target-controlled infusion — инфузия с целевой концентрацией; скорость рассчитывается по PK-модели |
| Cp | Концентрация в плазме (мкг/мл = мг/л) |
| Ce | Концентрация в месте действия (эффект-компартмент), запаздывает относительно Cp через ke0 |
| ke0 | Константа равновесия «плазма ↔ эффект» (мин⁻¹): Marsh 0.26, Schnider 0.456 |
| V1, V2, V3 | Объёмы центральной и двух периферических камер (л) |
| CL1, CL2, CL3 | Клиренс элиминации и межкамерные клиренсы (л/мин) |
| k10, k12, k21, k13, k31 | Микроконстанты: `k = CL / V` |
| LBM | Lean body mass (безжировая масса) по James (кг) |
| Болюс (нагрузка) | Начальное быстрое введение для достижения цели: `C·V1` (мг) |
| Начальная скорость R0 | `C·(CL1+CL2+CL3)` (мг/мин) — скорость сразу после болюса |

## 6. Правила расчёта TCI

### 6.1 Параметры модели (формулы)

**CALC-TCI-01.** Параметры модели — единственный источник формул (§5.2); UI и прочие функции их не дублируют. Ветвления по имени препарата ⛔ нет — есть ветвление по **модели** (данные), что допустимо и зафиксировано.

**CALC-TCI-02. Микроконстанты** (обе модели):

```
k10 = CL1 / V1    k12 = CL2 / V1    k21 = CL2 / V2
k13 = CL3 / V1    k31 = CL3 / V3
```

**CALC-TCI-03. LBM (James) и BMI-ограничение** (Schnider):

```
муж.: LBM = 1.10·W − 128·(W/H)²
жен.: LBM = 1.07·W − 148·(W/H)²        (W кг, H см)
BMI = W / (H/100)²
```

BMI-ограничение: муж. < 42, жен. < 35 кг/м² (VAL-TCI-04).

### 6.2 Болюс и скорости (референсы, детерминированные)

**CALC-TCI-04. Болюс (нагрузка):**

```
D = C · V1          [мг]
```

**CALC-TCI-05. Начальная и установившаяся скорость:**

```
R0 = C · (CL1 + CL2 + CL3)    [мг/мин]
R∞ = C · CL1                  [мг/мин]
```

**CALC-TCI-06. Перевод в объёмные единицы и инвариант обратимости:**

```
R_mlh = R[мг/мин] · 60 / conc          (conc — мг/мл)
V_bolus = D / conc
t_bolus = V_bolus / R_bolus_max        (R_bolus_max — максимум насоса, мл/ч, ⚠️ OQ-TCI-5)
C' = R∞_mlh · conc / 60 / CL1          (обратный контроль: C' ≈ C)
```

**CALC-TCI-07. Ce-лаг (аналитический референс для тестов):**

```
Ce(t) = C · (1 − e^(−ke0·t))          (после ступенчатого выхода Cp на цель)
t(f) = −ln(1 − f) / ke0               (время достижения доли f цели)
```

### 6.3 Пошаговая симуляция (3-компартмент + эффект-компартмент)

**CALC-TCI-08. Механика симуляции.** Для воспроизведения поведения TCI-насоса (образец Perfusor Space) движок ведёт дискретную симуляцию по времени:

1. Состояние — вектор (A1, A2, A3, Ce) масс препарата/концентраций; начальное — нулевое (research-tci §6.4: TCI предполагает нулевую начальную концентрацию ✅).
2. Шаг по времени **dt**: 1 с на этапе болюса и первых 15 мин (высокая динамика), 10 с далее; горизонт ≤ 24 ч ⚠️ (OQ-TCI-7). Шаг фиксирован и одинаков на всех устройствах (детерминизм).
3. Ввод на каждом шаге: болюс — как мгновенная (в пределах шага) инфузия с ограничением по максимуму насоса; поддержание — скорость R(t), рассчитанная контроллером цели (см. ниже).
4. Обновление компартментов по микроконстантам (линейная система) и Ce через ke0:

```
dA1/dt = k21·A2 + k31·A3 − (k10 + k12 + k13)·A1 + InfRate
dA2/dt = k12·A1 − k21·A2
dA3/dt = k13·A1 − k31·A3
dCe/dt = ke0·(Cp − Ce)          Cp = A1 / V1
```

5. Порог: контроллер цели удерживает Cp (режим PLASMA) или Ce (режим EFFECT_SITE) на цели; при достижении — снижение ввода, при снижении цели — стоп и предсказание падения.

**CALC-TCI-09. Decrement time (время до пробуждения).** После остановки инфузии движок продолжает симуляцию падения Cp/Ce и фиксирует первый момент пересечения порога пробуждения (умолчание 1.5 мкг/мл, настраивается 1.0–2.0). Значение растёт с длительностью инфузии (проверяется как свойство).

### 9.3 Сценарии TalkBack TCI

1. Открытие S-TCI → первым читается: «Пропофол, режим TCI, выберите модель».
2. Выбор Schnider → озвучиваются появившиеся поля: «Рост, сантиметры», «Возраст, полных лет», «Пол».
3. Ввод цели → через паузу объявление болюса и скорости с единицами.
4. Предупреждение BMI/цели → читается сразу, без перевода фокуса.
5. График — `stateDescription` «график Cp и Ce; значения доступны в подписи ниже» (числовые значения дублируют график).
