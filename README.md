# Калькулятор скорости инфузии

Android-приложение для расчёта скорости инфузии по концентрации препарата и обратного расчёта дозы.

> **Справочный инструмент.** Приложение не является медицинским изделием, не содержит назначений
> и не заменяет клиническое решение и проверку настроек инфузионного насоса.

## Возможности

- **Единая форма:** доза → скорость (мл/ч) и скорость → доза, без переключателя направления.
- **Концентрация из предустановок:** выбор одним нажатием; концентрации редактируются списком в едином редакторе препарата, а новая концентрация добавляется чипсом в блоке «Концентрация» на экране расчёта.
- **Единицы:** доза (мкг/кг/мин, мг/ч, ЕД/мин и т.д.) — свойство схемы препарата; масса препарата вводится в любых единицах (мкг/мг/г/ЕД/МЕ/мэкв) и конвертируется при расчёте.
- **Вес пациента** задаётся при запуске и редактируется кнопкой «весы 70 кг» в шапке каталога; действует для всех препаратов сессии.
- **Папки:** новая папка создаётся отдельным диалогом, долгое нажатие на чипс — переименование или удаление, «Настройки папок» — карточка в настройках.
- **Выход:** «Назад» с главного экрана спрашивает подтверждение.
- **Уведомление TCI:** открывает экран TCI, содержит действия «Пауза», «Выставил(а)» и «Стоп».
- **Встроенный каталог:** норадреналин, адреналин, добутамин, левосимендан, пропофол, дексдор, рокуроний, нитроглицерин, допамин, мидазолам — со схемами дозирования и типовыми разведениями.
- **Папки:** пользовательские папки-чипы в каталоге; препарат раскладывается по папкам с экрана расчёта, «Все» показывает весь каталог.
- **Пропофол TCI:** карточка-поводырь для обычного шприцевого насоса без режима TCI — модель Marsh/Schnider, Cp/Ce, болюс, шаговая программа скоростей на 5 минут, живая сессия с часами и прогнозом пробуждения; сессия продолжается в фоне и восстанавливается после перезапуска.
- **Предупреждения о дозах** (выше диапазона), валидация ввода, ограничение вывода дозы тремя знаками.
- **RU/EN**, локально (Room + DataStore), без сети; язык переключается в настройках (Android 13+).
- **О программе:** версия, автор и контакты.

## Стек

Kotlin 2.4.21 · AGP 9.5.1 · Gradle 9.8.2 · Jetpack Compose (BOM 2026.09.00) ·
Navigation 3 1.2.1 · Room 3.0.3 · DataStore · Koin 4.2.2 · AndroidX ViewModel.

Проверки: JUnit, Robolectric, Roborazzi (скриншоты), ktlint, detekt.

`compileSdk 37` · `targetSdk 36` · `minSdk 24`.

## Структура

```
app/                  Compose UI, Navigation 3, Room, DataStore, Koin
  di/                 Koin-модуль
  ui/viewmodel/       ViewModel экранов
  data/               Room, репозиторий, сид каталога
core-engine/          чистый JVM-движок расчётов на BigDecimal
docs/                 ТЗ, дизайн-документ, техплан, исследования
preview/              макеты и скриншоты
```

## Сборка

Нужны JDK 21+ и Android SDK (compileSdk 37).

```bash
./gradlew :core-engine:test :app:testDebugUnitTest :app:assembleDebug
./gradlew :app:ktlintCheck :app:detekt
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

`local.properties` с путём к SDK не коммитится.

## Ограничения

Дозы и разведения в каталоге — ориентировочные, требуют сверки с местным протоколом
и инструкцией к препарату. Пользовательские препараты помечаются как непроверенные.
